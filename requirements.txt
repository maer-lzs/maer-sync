# The runtime of the Mär sync service, pinned with hashes.
#
# The service CODE and its tests are standard library only. Serving it is
# not: an ASGI server has to exist, and uvicorn without its `[standard]`
# extra carries no WebSocket, while `/v1/changes` needs one.
#
# The server half is pure-python with exactly ONE wheel each, so a single
# hash covers every platform. That is why `wsproto` and not `websockets`:
# the latter ships a wheel per platform, and a pinned file would then either
# carry dozens of hashes or quietly stop working on the machine it was not
# generated on.
#
# THE CRYPTO HALF BREAKS THAT PROPERTY, and it is named here rather than
# discovered later. `cryptography` is compiled; it publishes 45 wheels for
# one version and pulls `cffi`, which publishes 99. So the hashes below are
# per platform, and the platforms are a CHOICE:
#
#   macOS on arm64 and x86_64, Linux on x86_64 and aarch64 (glibc and musl).
#
# Not covered, deliberately: Windows, PyPy, free-threaded builds, and the
# architectures nobody here runs (ppc64le, armv7l, s390x, i686). On one of
# those, `--require-hashes` fails loudly with "no matching distribution"
# instead of installing something unpinned. Adding a platform means adding
# its hashes, and that is a one-line change per wheel.
#
# The `abi3` wheels carry "this Python and upwards", so a single set covers
# 3.10 through 3.14; `cffi` is built per version and therefore appears
# several times.
#
# Install with the hashes ENFORCED, otherwise the pinning is decoration:
#   python3 -m pip install --require-hashes -r requirements.txt
