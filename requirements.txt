# The runtime of the Mär sync service, pinned with hashes.
#
# The service CODE and its tests are standard library only. Serving it is
# not: an ASGI server has to exist, and uvicorn without its `[standard]`
# extra carries no WebSocket, while `/v1/changes` needs one.
#
# Everything here is a pure-python wheel with exactly ONE file, so a single
# hash per package covers every platform. That is why `wsproto` and not
# `websockets`: the latter ships a wheel per platform, and a pinned file
# would then either carry dozens of hashes or quietly stop working on the
# machine it was not generated on.
#
# Install with the hashes ENFORCED, otherwise the pinning is decoration:
#   python3 -m pip install --require-hashes -r requirements.txt
